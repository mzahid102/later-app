# Later

Voice-first reminders for Android. Say what you need to do, it becomes a task with a reminder.

## Install

Open the latest release on your phone, download Later.apk, and open it. Allow installs from your browser when Android asks.

Every push to main builds a new APK automatically (see the Actions tab).

## Add the widget

Long-press your home screen > Widgets > Later. Tap the mic to record, tap the text to open the app.
